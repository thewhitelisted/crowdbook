crowdbook 0.14.1 fixes the learning environment's quotes: a smaller size at a price where the seat
already quotes now shrinks that quote in place, where 0.14.0 ignored it.

## Install

```bash
pip install crowdbook-engine==0.14.1 crowdbook-analysis==0.14.1
```

From PyPI, as is `crowdbook`, the client for served markets: wheels for Linux (x86-64 and arm64,
manylinux) and macOS (Apple silicon, 14 or later), for Python 3.12 and every later version. Start
with [docs/quickstart.md](https://github.com/thewhitelisted/crowdbook/blob/v0.14.1/docs/quickstart.md)
and [docs/tutorial.md](https://github.com/thewhitelisted/crowdbook/blob/v0.14.1/docs/tutorial.md).

## Fixed

- **A smaller size at the same price shrinks the seat's quote**
  ([python/README.md](https://github.com/thewhitelisted/crowdbook/blob/v0.14.1/python/README.md)).
  When `step_orders` or an action asked for a quote at the price the seat's quote already rested
  at, 0.14.0 left it at its old size; asking for 2 lots kept 5 resting. Now a smaller size, or a
  tighter position limit, shrinks the quote with a modify, which keeps its place in the queue. A
  larger size still leaves it as it is: growing in place would lose the place. Sizes are as the
  seat last heard them, so a shrink that crosses fills on the way, leaving less than it asks for,
  goes to the back of the queue.
- The library notes say that a take cancels only the quote on the side it takes from: the row's
  quote there waits until the next decision, and the other side's is still placed in the same
  step.

## Changes that may need yours

- **Learning episodes can differ from 0.14.0.** The action-based steps share the quoting with
  `step_orders`, so a join, improve or behind action whose size is smaller than the quote already
  at that price now shrinks it too. The learning pool's golden hash changes for that reason; the
  simulator's other golden runs keep theirs. Rerun evaluations and benchmarks of learning seats
  before comparing them with results from 0.14.0.
- Scenario files, session files and the protocol keep their version numbers, and sessions
  recorded by earlier versions still replay.
